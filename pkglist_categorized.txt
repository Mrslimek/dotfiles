## 🧠 AI & Core Development
- **zed** — High-performance code editor written in Rust.
- **cherry-studio** — Desktop IDE for multiple LLMs.
- **docker / docker-compose** — Containerization and service orchestration.
- **go** — Go programming language environment.
- **uv** — Modern Python package and version manager.
- **overmind-bin** — Process manager for Procfile-based apps.
- **postman-bin / pgadmin4-bin / pgcli** — API testing and PostgreSQL management tools.
- **pyenv / python-pipenv** — Legacy Python management (Better not install it on fresh system and use uv).

## 🖥️ Window Manager & Wayland
- **vicinae** — Raycast-compatible focus launcher.
- **hyprland** — Dynamic tiling Wayland compositor.
- **hyprlock / hypridle** — Screen locker and idle management daemon.
- **hyprpaper / hyprsunset** — Wallpaper utility and blue light filter.
- **hyprpolkitagent** — Privilege elevation (Polkit) agent.
- **nwg-displays / nwg-look** — Display configuration and GTK theme settings.
- **dunst** — Notification daemon.
- **satty** — Screenshot tool with annotation support.
- **wev** — Wayland event viewer for debugging keys/input.
- **wlopm** — Wayland output power management.

## 🛠️ System Reliability & Low-level
- **sbctl / efitools / efibootmgr** — Secure Boot management stack.
- **snapper** — Btrfs snapshot management for system rollbacks.
- **ly** — TUI display manager for login.
- **zram-generator** — RAM optimization via compressed swap.
- **power-profiles-daemon / powertop** — Power management and battery optimization.
- **amd-ucode / xf86-video-amdgpu** — CPU microcode and GPU drivers for AMD.

## 📂 File Management & CLI Tools
- **nautilus / tumbler** — GNOME file manager and thumbnail generator.
- **eza / fd / dust / dysk** — Modern Rust-based alternatives for ls, find, du, and df.
- **stow** — Symlink farm manager.
- **paru** — Feature-rich AUR helper.
- **zsh** — Interactive shell with custom configs.
- **git-delta** — Syntax-highlighting pager for git.
- **htop / wget / rsync** — Essential system monitoring and networking tools.
- **xdg-ninja** — Script to clean up the home directory.

## 🌐 Internet & Communication
- **zen-browser-bin / firefox / chromium** — Browsers (Zen as primary, Chromium/firefox for dev).
- **telegram-desktop / element-desktop** — Messengers.
- **qbittorrent / transmission-gtk** — BitTorrent clients.
- **xray / openvpn** — Network security and proxy tools.

## 🎨 Media, Visuals & Fonts
- **imv** — Fast image viewer for Wayland.
- **obsidian** — Knowledge base and Markdown note-taking.
- **anki** — Spaced repetition flashcards.
- **adw-gtk-theme / kvantum-theme-libadwaita-git** — Core Libadwaita rice components.
- **bibata-cursor-theme-bin / papirus-icon-theme** — Cursors and icons.
- **ttf-jetbrains-mono / ttf-iosevka-nerd / ttf-opensans** — System and coding fonts.
