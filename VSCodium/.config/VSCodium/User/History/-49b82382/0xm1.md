# VK Bot

VK Bot for searching company information using Podruchniy service API.

## Project Structure

```
app/
├── handlers/       # Entry point for VK messages
├── actions/        # Business logic (extracted for testability)
├── services/       # External service integrations
├── utils/          # Formatting utilities (vkbottle Formatter)
└── config.py       # Configuration with pydantic-settings
```

### Packages

- **`app/handlers`** - VK message handlers. If a handler contains significant business logic, it should be extracted to `app/actions` for better testability.
- **`app/actions`** - Business logic layer. Action classes can be instantiated with test data independently from VK context.
- **`app/services`** - External service integrations. Each service is an object-oriented wrapper around an external API.
- **`app/utils`** - Helper functions. Formatting utilities use vkbottle's `Formatter` for message markup.

### Code Style

- **Linter**: `ruff`
- **Type checker**: `ty`

## Setup

### Production

1. Install dependencies:
   ```bash
   uv sync
   ```

2. Configure environment variables (see [Configuration](#configuration)).

3. Run:
   ```bash
   python main.py
   ```

### Development

1. Install dependencies with dev extras:
   ```bash
   uv sync --extra dev
   ```

2. Run linter:
   ```bash
   uv run ruff check
   ```

## Configuration

Create a `.env` file based on `.env.example`:

```bash
cp .env.example .env
```

### Required Variables

- `VK_TOKEN` - VK Bot token from [VK Group Settings](https://vk.com/group<GROUP_ID>?act=manage)
- `PODRUCHNIY_BACKEND_API_BASE_URL` - Podruchniy API base URL
- `PODRUCHNIY_BACKEND_API_USERNAME` - Bot account username
- `PODRUCHNIY_BACKEND_API_PASSWORD` - Bot account password

### Optional Variables

- `PODRUCHNIY_BACKEND_API_FIND_BY_ID_PARTY_ENDPOINT` - Company search endpoint (default: `/api/v1.0/portal/complete-data/profile/`)
- `PODRUCHNIY_BACKEND_API_TOKEN_ENDPOINT` - Auth token endpoint (default: `/api/token/`)
- `PODRUCHNIY_BACKEND_API_REFRESH_ENDPOINT` - Token refresh endpoint (default: `/api/token/refresh/`)
- `LOG_LEVEL` - Logging level (default: `INFO`)

### Podruchniy Service Setup

1. Create a bot account in the Podruchniy service.
2. Add the bot credentials to your `.env` file:
   ```
   PODRUCHNIY_BACKEND_API_USERNAME=your_bot_username
   PODRUCHNIY_BACKEND_API_PASSWORD=your_bot_password
   ```

The bot will automatically authenticate and obtain access/refresh tokens on startup.
