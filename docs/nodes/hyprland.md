# Hyprland

## Role

Wayland compositor: tiling, keybinds, IPC. Configured in Lua; session started by uwsm; shell on top is Noctalia.

## Facts

- hyprland 0.57.1; config in `~/.config/hypr` (Lua); plugins via hyprpm
