# xdg-desktop-portal

## Role

Portal service: D-Bus APIs desktop apps use for file dialogs, screencast, settings, etc. Routes requests to per-desktop backends.

## Facts

- Backends: xdg-desktop-portal-hyprland + xdg-desktop-portal-gtk
