# Noctalia Shell

Excellent shell.

## Role

Desktop shell for Hyprland. Single process, started via `uwsm app -- noctalia`.

## Out of the box

Notifications, top bar, power management (power-profiles-daemon), window switcher, media player (MPRIS), settings GUI, wallpapers — plus control center, launcher, lock screen, OSD, night mode, and much more.

## v5

Ground-up rewrite in C++. Dropped the Quickshell/QML stack. No Qt/GTK, talks Wayland directly. Memory per monitor cut ~6x (from ~300 MB). Stable since 5.0.1. Development speed up. This machine runs v5 (noctalia-git 5.4.1).

## Verdict

IMO the best graphical shell among all Linux distro environments.
