# PipeWire

## Role

Multimedia server. Everything outputs here: MPD (via the PulseAudio API), Bluetooth audio (via BlueZ). PulseAudio/JACK compatibility layers included.

## Facts

- pipewire-alsa, pipewire-pulse, pipewire-jack, gst-plugin-pipewire installed
- Session management by WirePlumber
