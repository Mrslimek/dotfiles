# systemd --user

## Role

Per-user service manager. Runs the entire session stack as user units: PipeWire stack, MPD, Syncthing, Vicinae, MPRIS bridges, gnome-keyring. uwsm plugs the compositor into it, so the whole session lives in systemd.
